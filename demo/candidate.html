Access & Audit — AIR Blackbox Governed

This candidate profile is governed by AIR Blackbox. Every access to this page — by a person or an AI assistant — is recorded on a tamper-evident audit chain: each record's hash is linked to the record before it (HMAC-SHA256), and records carry Ed25519 signatures anyone can verify with the public key alone. No visitor data is stored; only that an access occurred, and when.

Audit status: checking the chain…

Don't take this page's word for it. The audit chain is queryable directly: https://air-mcp.fly.dev/demo/status returns the live record count and integrity verdict as JSON from the audit server — independent of anything rendered here. Signed evidence bundles are verifiable offline against the server's public key with the open-source air-evidence verify tool.

The same governance is available for any AI agent: AIR Blackbox publishes a claude.ai-compatible connector (https://air-mcp.fly.dev/mcp) that adds approval gates on reject/advance decisions, blocks inference of protected attributes, and exports signed evidence bundles. A five-minute setup guide lives at airblackbox.ai/demo/get-started.
